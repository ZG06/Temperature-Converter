# Temperature-Converter

The application helps to convert temperatures from 5 different scales.

All you need to do is to:
1. Select a unit you want to convert a temperature from.
2. Select a unit you want to convert a temperature to.
3. Input a temperature you want to convert

## Installation Instruction:
    $ git clone https://github.com/ZG06/kivy-temp-converter.git
    $ cd kivy-temp-converter
    $ chmod +x main.py
    $ python3 main.py
